# Наталья Сорокина — телесная терапия и Ребалансинг в Воронеже

Одностраничный сайт телесного терапевта: метод Ребалансинг, форматы сессий, отзывы, контакты.

## Стек

- Чистый HTML/CSS/JS, без фреймворков и сборщика в рантайме
- Шрифты: Cormorant Garamond, Manrope (Google Fonts)
- Vite — только для локального превью

## Запуск

```bash
npm install
npm run dev
```

Либо просто открыть `index.html` в браузере — сайт полностью статический.
